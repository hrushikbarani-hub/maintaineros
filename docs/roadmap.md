# Roadmap

## Shipped in 0.2

Public GitHub captures, issue/PR evidence links, SQLite history, score explanations, action states, dashboard, CLI, CSV/JSON/Markdown reporting, package builds and CI.

## Shipped in 0.3

Per-repository capture policies in the browser, API and CLI; immutable historical policy; two-capture metric/score comparisons and sampled-item differences with explicit source/policy/coverage caveats.

## Next focused increments

1. Named project policy presets (libraries vs applications) and component-level trend charts.
2. ETag caching, persisted import-job states and retries for larger repositories.
3. Opt-in scheduled captures and a GitHub App installation flow.

Accounts, PostgreSQL, and team ownership should follow demonstrated multi-user demand. New metrics must include coverage information and an actionable explanation.
